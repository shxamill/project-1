# Contributing

This is a static HTML/CSS learning project.

## Guidelines

- Keep the layout responsive and use semantic HTML.
- Preserve the relative paths used by images and stylesheets.
- Avoid adding third-party logos, images, or copy unless their usage rights are clear.
- Do not commit secrets, personal data, or unrelated generated files.

## Verify changes

Open index.html in a browser (or use python -m http.server 8000) and check the page at desktop and mobile widths. Confirm that all images load and that the browser console has no new errors.

There is currently no package manager, build step, or automated test suite.
